## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach
Use two pointers, one at the beginning and one at the end. Swap the characters and move both pointers toward the center.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
A single-character string is already reversed, so no swap is needed.
